# Prasham Doshi - Portfolio

A responsive, dependency-free portfolio site focused on software development, web development, and AI/ML roles.

## Run locally

```powershell
npm.cmd run dev
```

Open `http://127.0.0.1:4173`.

## Validate and build

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

The production-ready static files are written to `dist/`.

## Customize

- Content: `index.html`
- Visual system and responsive styles: `styles.css`
- Theme, navigation, reveal effects, and interactions: `script.js`
- Resume: `assets/prasham-doshi-resume.pdf`
